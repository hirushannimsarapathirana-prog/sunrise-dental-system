# Sunrise Dental Clinic Management System

## Description

A Java and MySQL based dental clinic management system.

## Technologies

- Java
- Maven
- MySQL
- Gson
- HTML/CSS/JavaScript
- Git
- GitHub
- Postman

## Main Features

- Login
- Appointment Management
- Appointment Search
- Appointment Update
- Appointment Delete
- Billing
- Validation

## Backend

Java HTTP Server

## Database

MySQL

## Testing

Postman API Testing

## Version Control

Git and GitHub
