How Can We Help?

Find useful information about using the clinic management system.

New Appointment

Use the New Appointment section to create a new dental appointment. Enter the patient's information, dentist, treatment, date and appointment time.

Manage Appointments

Search for an appointment using the appointment number. You can view appointment details, edit information, update changes or delete an appointment.

Billing

Create a bill by entering the appointment number and selecting the treatment. Treatment cost is suggested automatically and the total cost is calculated.

Print Bill

After creating a bill, use the Print option to open the printable invoice. Select Print Bill to print the patient's billing information.

Frequently Asked Questions

Common questions about the system.

How do I create an appointment?

Go to New Appointment, enter the required patient and appointment information, then click Create Appointment.

How can I find an existing appointment?

Open Manage Appointments and enter the appointment number in the search field. Click View to display the appointment.

Can I edit an appointment?

Yes. Search for the appointment, click Edit, make the required changes and then click Update.

How is the bill total calculated?

The total cost is calculated by adding the treatment cost and the consultation fee.

What happens when I click Clear?

The billing form information is removed so you can enter a new bill.
